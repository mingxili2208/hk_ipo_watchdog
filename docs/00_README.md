# HK IPO Watchdog 文档包

## 项目定位

本项目是一个面向个人使用的 **港股打新情报雷达 + 策略筛选 + AI 摘要推送系统**。

系统目标不是自动交易，也不是替用户做投资决策，而是：

1. 实时或准实时抓取港股 IPO / 打新相关信息；
2. 将不同来源的数据标准化；
3. 根据用户预设策略进行筛选、打分和分级；
4. 使用大模型生成简洁摘要、风险提示和触发原因；
5. 通过 Telegram / 邮件 / Bark / Server 酱等方式推送；
6. 保存历史数据，便于后续回看和策略回测。

## 建议实现顺序

第一阶段只实现 MVP：

1. IPO 日历抓取；
2. 配发结果抓取；
3. 策略规则打分；
4. LLM 摘要；
5. Telegram 推送；
6. SQLite 存储。

第二阶段再加入：

1. 暗盘监控；
2. 多源交叉验证；
3. Web Dashboard；
4. 策略回测；
5. PostgreSQL / Redis / Celery。

## 注意事项

- 本项目不提供投资建议，只做信息整理和策略过滤。
- 数据源页面结构和 API 字段可能变化，实现时需要容错。
- 如果使用券商 API，需要遵守券商 API 权限和行情许可。
- 如果部署在 VPS，需要妥善管理 API Key、Telegram Token、邮箱授权码等敏感信息。
